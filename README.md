# BuySell
This is a buggy program used for buying and selling stuff.
## Isn't this meant to be part of BatOS?
Yes, BatOS is hosted [here](techspertgit2.github.io/BatOS) but technically no as well, because BatOS is a different batch file to BuySell.
## Can I have the link to get BuySell
Yes, but you NEED TO KNOW that BatOS and Buysell HAVE to be in the same folder otherwise BuySell won't launch from BatOS! OK, Here's the link to [get BuySell](github.com/TechspertGit2/BuySell/raw/refs/heads/main/BuySell(extractme).rar).
## How does it work?
I can teach you how to view the coding! If you have VSCode installed, GREAT! If you don't, that's fine, because you can view it with Notepad! First, hold down Windows on your keyboard and click R, then you will get a little box for text where you can launch stuff. What you wanna do is type: notepad "".
In the "", you put the directory that BuySell is in, then BuySell.bat at the end. It should look a bit like: notepad "C:/Users/%username%/OneDrive/Desktop/BuySell.bat". If you do have VSCode, replace "notepad" with "code".
